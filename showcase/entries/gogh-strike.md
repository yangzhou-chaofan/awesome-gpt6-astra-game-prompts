# Gogh Strike

> [:@petergostev](https://x.com/petergostev) · [📜 原帖](https://x.com/petergostev/status/2096013280519016608)


A painter-themed browser shooter set in Van Gogh's town, with bot teammates and rivals. **Creator:** [Peter Gostev](<https://x.com/petergostev>) · **Tools / format:** Three.js, Blender The author credits Astra and Blender for the game. The current source describes single-player matches with bots; online multiplayer is not implemented. [Original post](<https://x.com/petergostev/
