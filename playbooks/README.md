## 为什么单独开一层

`prompts/` 里的 recipe 回答"**这个 prompt 长什么样**"；playbook 回答"**我想做个 X，该怎么组合**"。
新手抄 recipe 容易翻车，因为不知道背后的玩法套路；playbook 把套路显式化 —— 它也是站外
传播（教程、视频、newsletter）最容易被引用的干货单元。
