## Field map

- `original_post` — the author's original X post.
- `media_url` — the preview asset referenced by the upstream list (raw GitHub), **not** re-hosted here.
- `prompt` — verbatim text from the upstream list. Some upstream entries note the original chat prompt
  was never published; where so, the list's reconstructed/spec text is quoted as-is.
- `source_list` / `source_license` — where it came from and under what terms.

## Removal / correction

If you are the author of a post and want it removed, open an issue with the `original_post` URL and it
will be removed. Prompts and previews remain the property of their original authors.
